# 页面上下文

## 抽奖应用页面

- **路径**: `/src/pages/LotteryPage.vue`
- **描述**: 抽奖应用主页面，包含三个主要区域：
  1. 左侧抽奖设置区：配置参与抽奖人员和抽奖规则
  2. 右侧抽奖动画展示区：展示抽奖过程和结果
  3. 底部中奖名单区：展示每轮抽奖的中奖记录
- **组件依赖**:
  - `ParticipantManager.vue` - 管理参与者列表
  - `LotterySettings.vue` - 抽奖设置控制
  - `LotteryDisplay.vue` - 抽奖动画和结果展示
  - `WinnersList.vue` - 中奖名单展示
- **状态管理**: 
  - 使用Vue的响应式API管理参与者列表、中奖名单和抽奖状态
  - 使用ref和computed管理数据和计算属性
- **页面布局**:
  - 响应式网格布局，在大屏幕上为三列布局，小屏幕上为单列布局
  - 使用UnoCSS提供的工具类实现响应式设计
  - 支持暗色模式，通过CSS变量实现主题切换
- **主要功能**:
  - 参与者管理：添加、删除、批量导入参与者
  - 抽奖设置：配置每轮抽取人数
  - 抽奖过程：随机滚动展示参与者名称
  - 抽奖结果：展示中奖者名单
  - 历史记录：保存每轮抽奖结果和时间
- **数据流**:
  1. 用户通过ParticipantManager组件添加参与者
  2. 用户通过LotterySettings组件设置每轮抽取人数并开始抽奖
  3. LotteryDisplay组件展示抽奖过程并生成结果
  4. 抽奖结果添加到历史记录并由WinnersList组件展示
  5. 已中奖者从可参与抽奖的名单中排除
- **交互逻辑**:
  - 开始抽奖前检查参与者数量是否足够
  - 抽奖过程中随机展示参与者名称
  - 用户可手动停止抽奖并查看结果
  - 每轮抽奖结果自动记录并展示
