# 注意事项与坑点记录

## 开发注意事项

### UnoCSS相关

- **暗色模式切换**：确保所有组件都添加了`dark:`前缀的样式类，特别是背景色和文本颜色
- **响应式设计**：使用`sm:`, `md:`, `lg:`等前缀时注意断点的一致性，避免布局在特定尺寸下出现问题
- **自定义CSS变量**：使用CSS变量时需要在`:root`和`.dark`选择器中都定义对应的变量

### Vue 3相关

- **响应式API**：使用`ref`和`reactive`时注意值的解包，特别是在模板中使用`.value`
- **计算属性**：`computed`属性依赖的响应式数据发生变化时才会重新计算，注意依赖收集
- **组件通信**：使用`props`和`emit`进行父子组件通信，避免直接修改props

### 性能优化

- **大列表渲染**：当参与者列表较大时，考虑使用虚拟滚动优化渲染性能
- **频繁操作**：抽奖动画中的频繁DOM更新，考虑使用`requestAnimationFrame`优化
- **计算缓存**：对于复杂计算，使用`computed`而非方法调用，利用Vue的缓存机制

## 已知问题与解决方案

### 批量导入参与者

**问题**：从剪贴板批量导入参与者时，可能包含空行或重复名称

**解决方案**：
- 导入前过滤空行
- 检测并合并重复名称
- 添加导入预览和确认步骤

### 抽奖动画性能

**问题**：当参与者数量较多时，抽奖动画可能出现卡顿

**解决方案**：
- 限制动画中显示的参与者数量
- 使用CSS动画代替JavaScript动画
- 考虑使用Canvas绘制复杂动画

### 移动端适配

**问题**：在小屏幕设备上，三列布局显示不佳

**解决方案**：
- 已使用响应式网格布局，在小屏幕上切换为单列
- 考虑为移动端优化交互方式
- 调整字体大小和间距以提升可读性

## 技术债务

- **类型定义**：当前缺少TypeScript类型定义，需要添加接口和类型声明
- **状态管理**：随着功能增加，考虑引入Pinia进行状态管理
- **测试覆盖**：需要添加单元测试和E2E测试
- **组件文档**：需要完善组件文档，便于团队协作

## 浏览器兼容性

- 主要支持现代浏览器（Chrome, Firefox, Safari, Edge）
- 不支持IE11及以下版本
- 移动端浏览器支持iOS Safari和Android Chrome

## 部署注意事项

- 使用`pnpm build`构建生产环境代码
- 确保服务器配置正确的MIME类型
- 考虑使用CDN加速静态资源加载
- 启用GZIP或Brotli压缩减小传输体积
