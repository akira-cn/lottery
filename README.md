# 抽奖系统

基于 Vue 3 + Composition API 和 UnoCSS 开发的抽奖应用，支持多人参与、多轮抽奖和中奖记录展示，并且支持亮色/暗色主题切换。适用于公司年会、活动抽奖、课堂随机点名等场景。

## 功能特点

- **参与者管理**
  - 添加、删除单个参与者
  - 从剪贴板批量导入参与者名单
  - 一键生成随机参与者用于测试
  - 清空参与者列表

- **抽奖设置**
  - 配置每轮抽取人数
  - 智能限制抽取人数不超过可参与人数
  - 实时显示可参与抽奖人数

- **抽奖过程**
  - 动态随机滚动展示参与者名称
  - 手动停止抽奖并查看结果
  - 卡片式展示中奖结果

- **中奖记录**
  - 按轮次展示历史中奖记录
  - 显示每轮抽奖的时间和中奖人数
  - 自动防重复中奖，已中奖人员不再参与后续抽奖

- **用户体验**
  - 响应式设计，完美适配移动端和桌面端
  - 支持亮色/暗色主题切换
  - 简洁直观的界面设计

## 技术栈

- **前端框架**: Vue 3 + Composition API
- **构建工具**: Vite
- **样式系统**: UnoCSS (原子化CSS)
- **状态管理**: Vue 响应式API (ref, computed)
- **UI设计**: 自定义设计系统，基于CSS变量实现主题切换

## 使用指南

1. **添加参与者**
   - 在左侧面板的输入框中输入参与者昵称，点击"添加"按钮
   - 或点击"批量导入"按钮，从剪贴板导入多个参与者（每行一个名称）
   - 也可以点击"生成随机参与者"按钮快速创建测试数据

2. **设置抽奖规则**
   - 使用数字调节器设置每轮抽取的中奖人数
   - 系统会自动限制抽取人数不超过可参与人数

3. **开始抽奖**
   - 点击"开始抽奖"按钮开始抽奖过程
   - 抽奖过程中会随机滚动展示参与者名称
   - 点击"开奖"按钮停止抽奖并查看结果

4. **查看中奖记录**
   - 在底部区域可以查看所有历史中奖记录
   - 每轮抽奖的结果会自动添加到历史记录中
   - 已中奖人员不会再次参与后续抽奖

## 自定义与扩展

- 修改 `App.vue` 中的 CSS 变量可以自定义主题颜色
- 可以在 `ParticipantManager.vue` 中修改随机生成的参与者名称
- 可以调整 `LotteryDisplay.vue` 中的动画效果和展示方式
